# Off-Road Semantic Segmentation using U-Net

## 🚀 Overview

This project focuses on semantic segmentation of off-road terrain using a U-Net deep learning model. The goal is to classify each pixel into terrain categories for autonomous navigation.

## 🧠 Model

* Architecture: U-Net
* Classes: 6 terrain classes
* Loss Function: CrossEntropyLoss
* Optimizer: Adam

## 📊 Results

* Achieved IoU up to **0.71**
* Progressive improvement across epochs

## 📂 Dataset

* Offroad Segmentation Dataset
* Preprocessed with resizing (256x256) and normalization
